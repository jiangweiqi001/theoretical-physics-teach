# Learning Roadmap

## Mastery levels

1. **Interpretation:** explain the objects, symbols, assumptions, and physical question.
2. **Reconstruction:** reproduce the central derivation or supporting proof without hidden steps.
3. **Synthesis:** translate source conventions and identify assumptions that change a result.
4. **Implementation:** map theory and approximations to algorithms, inputs, outputs, and validation observables when code is in scope.
